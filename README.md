# MPSP Benchmarking Repository
This repository provides resources for benchmarking algorithms related to the Multi-Project Scheduling Problem (MPSP).  
  
It includes:
- Test instances in Microsoft Project™ (.mpp) format.
- VBA macro modules and ribbon customisation files for Microsoft Project™.
- Documentation and installation guides to support reproducibility and academic experimentation.
 
## Publication
This repository accompanies the article:  
- Poza, D., Araújo, A., De Antón, J., & Villafáñez, F. (2026). Bridging the Research-Practice Gap in Multi-Project Scheduling: A VBA-Based Decision Support Tool for Microsoft Project. **[International Journal of Industrial Engineering and Management](https://ijiemjournal.uns.ac.rs/index.php/ijiem)** (under review)

   The VBA macro implements the P-SGS/MINSLK algorithm, originally proposed in: 
- Villafáñez, F. A., Poza, D., López-Paredes, A., Pajares, J., & del Olmo, R. (2019). A generic heuristic for multi-project scheduling problems with global and local resource constraints (RCMPSP). **Soft Computing, 23(9), 3465–3479. [https://doi.org/10.1007/s00500-017-3003-y](https://doi.org/10.1007/s00500-017-3003-y)**
If you use this repository or its contents in your research, please consider citing the article once published.

## Source of the Original Instances
The original problem instances were obtained from the MPSPLib **[http://www.mpsplib.com/](http://web.archive.org/web/20250623032139/http://mpsplib.com/index.php)**, developed by **Jörg Homberger**.  
These have been converted into `.mpp` format for compatibility with Microsoft Project. Instance names follow the original source.  
All these `.mpp` instances are available in the following Github repository: **[MPSPLIBtoMPP](https://github.com/INSISOC/MPSPLIBtoMPP)**  
  
If you use these instances in your research, please also cite the original source:  
- Homberger, J. (2007). *A multi-agent system for the decentralised resource-constrained multi-project scheduling problem*. International Transactions in Operational Research, 14(6), 565–589.  
You can download the original instances from: **[mp_all.zip](http://web.archive.org/web/20240915061554/http://mpsplib.com/data/mp_all.zip)** or one by one from: **[http://mpsplib.com/download.php](http://web.archive.org/web/20240915061554/http://mpsplib.com/download.php)**
